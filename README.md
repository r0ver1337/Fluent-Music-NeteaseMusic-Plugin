# Fluent Music NeteaseMusic Plugin

## 支持的功能

- 网易云音乐游客访问、二维码登录、登录状态查询、本人账号资料、会话恢复及注销。
- 歌曲搜索、本人创建和收藏的歌单、完整歌单歌曲分页与歌曲信息。
- 每日歌曲和歌单推荐，以及明确区分的公开推荐回退。
- 标准、较高、极高、无损和 Hi-Res 音质目录及已授权歌曲播放；不绕过会员、试听或版权限制。
- LRC / YRC 歌词、逐字时间、翻译歌词与封面信息。
- 原生 weapi / eapi / xeapi 请求协议、Fluent Music API / C ABI 2、宿主文件与网络接口及 Windows DPAPI 会话保护。
